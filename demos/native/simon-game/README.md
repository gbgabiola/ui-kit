# The Simon Game

Simon Game is a classic electronic game and this is the online version of it. This game creates a series of tones and light and requires a user to repeat the sequence.

## Built with:

- HTML5
- CSS3
- JavaScript
- jQuery

![Simon Game Screenshot](../../previews/demos/simon-game-light.png "Simon Game Screenshot")

Visit the [live preview](https://gbgabiola.github.io/ui-kit/demos/simon-game).
